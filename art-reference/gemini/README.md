the council session. They show the semi-realistic heroic, cinematic style the
owner chose and a global cast.

**Owner decision (2026-10-30):** the images in `approved/` are the official
visual target for each character and weapon. Until the game has subscribers,
characters are built with free or low-cost tools (about US$0–150, plan in
`build-recovery/council/v3/summary.html` §6). Professional versions matching
these images are funded later from subscription income.
